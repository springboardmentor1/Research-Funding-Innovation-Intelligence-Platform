# Funding Opportunities Dataset

This folder is reserved for funding opportunities, grants, and sponsoring agencies datasets.

## Purpose

- **Offline Caching**: Caching of active calls for proposals, proposal eligibility criteria, and agency specifications.
- **Grants Indexing**: Cataloging grant agency listings for structural indexing and metadata standardization checks.
- **Testing Fixtures**: Mock grant objects used in testing funding discovery routes and match algorithms.
- **Future AI Workflows**: Training datasets for grant matching engines that link active research profiles to funding calls.
