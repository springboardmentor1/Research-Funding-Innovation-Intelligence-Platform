# Publications Dataset

This folder is reserved for scientific literature and publication datasets.

## Purpose

- **Offline Caching**: Caching of academic papers, abstracts, and author details retrieved from sources such as OpenAlex.
- **Preprocessing & NLP**: Testing and refinement of natural language processing (NLP) pipelines (e.g., TF-IDF keyword extraction, embeddings generation).
- **Testing Fixtures**: Storing mock API responses for local unit testing of the publication module.
- **Future AI Workflows**: Training datasets for author classification and publication suggestion engines.
