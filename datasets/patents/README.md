# Patents Dataset

This folder is reserved for patent registrations and intellectual property datasets.

## Purpose

- **Offline Caching**: Storing patent specifications, CPC/IPC classification registries, and assignee metadata retrieved from sources like The Lens API.
- **Classification Modeling**: Preprocessing patent keywords for technology classification modeling (CPC categorization mapping).
- **Testing Fixtures**: Mock patent response objects used in testing patent routers and API integrations.
- **Future AI Workflows**: Training sets for innovation scores calculation, TRL assessments, and competitor overlap alerts.
