# UI Frameworks

The following diagram represents the UI Framework of the project.

![UI Framework](images/ui_workflow.png)

## Frontend Technologies

### React.js
Used for developing reusable user interface components.

### Tailwind CSS
Provides responsive and modern styling.

### HTML5
Used for page structure.

### CSS3
Used for styling and layouts.

### JavaScript
Handles client-side interactions.

### Axios
Used for communicating with backend REST APIs.
